# 示例输入

```text
请使用 $captable 生成一份投融资股权结构表。

项目名称：示例科技
投前估值：人民币 90,000 万元
本轮投资金额：人民币 5,000 万元
ESOP：本轮融资完成后 3%

投前股东：
1. 创始人A，注册资本 500 万元，持股 50%
2. 员工平台B，注册资本 300 万元，持股 30%
3. 投资人C，注册资本 200 万元，持股 20%

本轮投资人：
1. 投资人1，投资 2,000 万元
2. 投资人2，投资 1,000 万元
3. 投资人3，投资 2,000 万元

本轮无老股转让。
暂无可转债、SAFE、认股权证或反稀释事项。
请输出 Excel，并保留公式和检查页。
```

## 预期输出

工作簿通常包括：

- `计算逻辑`
- `投后股权结构`
- `完全稀释后`
- `检查`

关键结果应包括：

- 新股单价；
- 各投资人新增注册资本；
- ESOP 新增注册资本；
- 各股东投后持股比例；
- 完全稀释后持股比例；
- 投前注册资本、投资金额、投后注册资本、持股比例合计等核对项。
