# CapTable Skill

一个用于生成投融资交易股权结构表的 Codex Skill，适合中国投融资交易文件语境下的注册资本口径、新股认购、老股转让、ESOP、完全稀释后股权结构和公式化核对。

## 适用场景

- 增资扩股
- 新股认购
- 老股转让
- 新老股混合交易
- ESOP / 员工持股平台
- 投资协议、股东协议、增资协议附件中的股权结构表
- 可转债、SAFE、认股权证、反稀释等潜在稀释事项的情景测算

## 可以生成什么

默认生成 Excel 工作簿，通常包含：

- `计算逻辑`
- `投后股权结构`
- `完全稀释后`，如适用
- `检查`

表格应包含可编辑输入、公式、投后持股比例、完全稀释后比例和自动核对项。

## 你需要提供的信息

通常提供以下信息即可：

- 项目名称
- 投前估值
- 本轮投资金额
- 投前股东名册
- 投前注册资本或股份数
- 各投资人投资金额
- ESOP 比例及计算口径
- 是否存在老股转让
- 是否存在可转债、SAFE、认股权证、反稀释等潜在稀释事项

## 示例输入

```text
请使用 $captable 生成一份投融资股权结构表。

项目名称：示例科技
投前估值：人民币 90,000 万元
本轮投资金额：人民币 5,000 万元
ESOP：本轮融资完成后 3%

投前股东：
创始人A：注册资本 500 万元，持股 50%
员工平台B：注册资本 300 万元，持股 30%
投资人C：注册资本 200 万元，持股 20%

本轮投资人：
投资人1：2,000 万元
投资人2：1,000 万元
投资人3：2,000 万元

本轮无老股转让。暂无可转债、SAFE、认股权证或反稀释事项。
```

## 安装方法

将 `skill/captable` 文件夹复制到你的 Codex skills 目录：

```text
~/.codex/skills/captable
```

Windows 示例：

```text
%USERPROFILE%\.codex\skills\captable
```

复制后重启 Codex，或刷新 skills。

## 使用提示

你可以直接对 Codex 说：

```text
使用 $captable，根据以下股东名册、投前估值和投资金额，生成一份带公式的投后股权结构表。
```

如果交易结构不清楚，建议明确：

- ESOP 是投前预留还是投后增发；
- 投资款是否全部进入公司，还是部分用于受让老股；
- 交易文件采用注册资本口径、股份数口径，还是完全稀释口径；
- 是否存在可能影响股权结构的特殊权利或潜在稀释工具。

## 注意事项

本 Skill 仅作为交易测算和文件起草辅助工具。使用者仍需独立核对交易文件中的估值口径、ESOP 口径、注册资本、老股转让、反稀释及其他特殊安排。

公开分享前，请勿上传真实项目文件、真实股东名册、投资协议、客户名称、本机路径、身份证件号码、联系方式、银行账户、签名页或其他保密信息。
