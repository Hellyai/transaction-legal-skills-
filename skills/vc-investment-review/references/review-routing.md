# 审阅路由与身份识别（详细规则）

## 一、审阅场景识别

### 1. TS / Term Sheet
- 默认深度：**快速完整性审核**。
- 目标：在最短篇幅内确认 TS 是否"能签""该补什么"。
- 仅在用户明确要求"深度审核"时展开逐条法律分析。
- 审核重点清单见 `ts-review.md`。

### 2. 投资协议 / 增资协议 / 股权转让协议
- 重点审：交易执行、交割安排、Cap Table、尽调风险落实、违约责任、解除、
  多投资人是否互不承担连带责任。
- 不默认展开股东权利深度分析（那是股东协议的事）；但投资协议中若已含投资人权利
  条款，需与该轮股东协议核对一致。

### 3. 股东协议
- 重点审：投资人权利是否齐备，以及每项权利条款是否投资人友好。
- 权利清单与 Key Terms 输出见 `shareholder-agreement-review.md`。

### 4. 交割文件最终核验
- **仅在以下条件之一满足时启用**，否则不要默认展开：
  - 用户提供了章程、股东会决议、董事会决议、披露函、放弃函；或
  - 用户明确说"交割前审核 / 签署前审核 / 打款前审核"。
- 核验口径见 `closing-final-check.md`。

## 二、我方身份识别

依以下顺序判断并选择对应审阅重点（可叠加，例如"既有投资人 + 政府引导基金"）：

### 1. 新进投资人
重点：本轮估值、投资金额、我方股比、交割条件、投资人权利、退出安排、
尽调风险是否落实。

### 2. 既有投资人
额外重点：
- 上一轮投后义务是否履行；
- 上一轮违约责任是否被豁免 / 过度豁免；
- 既有回购、反稀释、优先认购、优先购买、共同出售、MFN、董事席位、
  保护性条款、信息权是否被削弱、推迟或放弃；
- 新老投资人权益是否实质一致；
- 必须同步生成一份"与上轮投资协议、股东协议的修改要点总结及指定方权益影响分析"；
- 专项分析至少覆盖：是否新增/发放/扩容 ESOP，指定方过往参与过几轮投资，各轮投资金额、投资单价或估值、
  取得股比及本轮后持股变化；
- 专项分析必须判断权利是否平等：本轮是否新增仅由新投资人享有的特殊权利、优惠待遇、优先顺位或更强行权机制，
  而指定方未同步享有，或指定方同类权利更弱、门槛更高、顺位更后、期限更短。

若缺少上轮文件或历史 Cap Table，应在输出中列明"无法判断项"，并提示需补充：
上轮投资协议、上轮股东协议、上轮章程/补充协议、历轮 Cap Table、工商登记资料、ESOP 决议或激励计划文件。

### 3. 政府引导基金 / 地方产业基金
额外关注：
- 落地、返投、地方基金考核；
- 落地主体设立；
- 税收 / 就业 / 研发 / 生产或运营承诺及未完成后果。

### 4. 其他产业投资人
结合自身战略诉求（业务协同、供应链、董事观察、信息权等）调整审阅重点。

### 身份不明时的处理
若从文件与对话中无法判断身份，**先向用户确认身份再展开**，不要假设。

## 三、身份 × 场景 组合速查

| 场景 \ 身份 | 新进 | 既有 | 政府引导/地方产业基金 |
|---|---|---|---|
| TS | 估值/股比/交割条件/权利骨架 | 同左 + 不削弱既有权利 | 同左 + 返投落地体现 |
| 投资协议 | 交易执行/Cap Table/尽调落实 | 上一轮义务履行/违约豁免/连带 + 上轮投资协议修改要点对比 | 返投承诺与落地主体 |
| 股东协议 | 权利齐备 + 友好度 | 逐项比对是否削弱 + 上轮股东协议修改要点对比 | 返投相关权利/承诺 |
| 交割核验 | 横向一致/签署齐备 | 既有权利未被夹带放弃 | 落地返投义务落实 |
