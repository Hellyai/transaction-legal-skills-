# 投资协议 / 增资协议 / 股权转让协议 审核规则

## 一、重点审核项
- 本轮估值
- 新进投资机构
- 投资总额
- 各投资人投资金额
- 我方股比
- 投前 / 投后 / 完全稀释 Cap Table
- 签署主体是否齐备
- 交割前提条件是否完整
- 交割前过渡期事项
- 交割后义务
- 法律尽调报告要点是否落实
- 违约责任
- 解除
- 多个投资人是否约定各自义务分别且不连带
- 资金用途
- 工商变更、股东名册、出资证明、章程备案等交割后安排

## 二、新进投资人专项审核

- 先加载 `new-investor-review.md`，建立本轮文件矩阵和投资主体—证券—权利映射
- 将重大尽调发现逐项映射至交割前提、陈述保证、特别赔偿或交割后义务
- 核查付款、交割、股东登记和权利生效是否同步，未交割或逾期时是否可解除并退款
- 核查陈述保证主体、披露机制、责任期限、赔偿上限及欺诈/故意违约例外
- 核查投资人之间义务是否分别且不连带，以及指定方是否承担其他投资人未履行风险
- 文件涉及经济或治理权利时，分别加载 `economic-rights-review.md` 和 `governance-review.md`
- 文件涉及 Cap Table、ESOP、估值、注册资本、单价、持股比例或完全稀释计算时，必须调用 `captable` skill
- 每项意见标注适用主体/证券、处理类型、优先级和证据状态

## 三、既有投资人额外审核
- 先加载 `existing-investor-review.md`，完成文件版本矩阵和主体—轮次—股权批次映射
- 文件涉及经济权利时加载 `economic-rights-review.md`；涉及董事会、股东会或否决权时加载 `governance-review.md`
- 文件包含 Cap Table、ESOP、估值、注册资本、投资单价、持股比例、完全稀释或反稀释计算时，必须调用 `captable` skill
- 上一轮投后义务是否已完整履行
- 股权结构是否正确
- 是否要求上一轮投资人过度豁免公司及创始人的违约责任
- 是否触发但未处理反稀释、优先认购、MFN 等权利
- 既有董事席位、否决权或信息权是否被削弱
- 与上轮投资协议逐项对比修改要点，包括交易结构、估值/投资单价、投资金额、交割前提、
  交割后义务、违约责任、解除、豁免/追认、投后义务履行情况
- 梳理指定方历史投资情况：过往参与轮次、各轮投资金额、投资单价或估值、取得股比、
  本轮前后股比变化
- 核查本轮是否新增/发放/扩容 ESOP，ESOP 是投前还是投后口径，是否稀释指定方，
  是否触发保护性条款、优先认购权、反稀释或其他同意权
- 核查本轮投资协议是否替代、终止、覆盖或重述前序轮投资协议；若有替代/终止安排，
  必须确认前序轮已发生的违约责任、交割后义务、赔偿责任、救济权、索赔权、回购触发、
  反稀释补偿和其他已产生权利是否明确保留
- 警惕"完整协议""取代此前约定""各方确认不存在争议/违约/其他权利义务""自本协议生效日起原协议终止"
  等表述变相消灭前序轮救济
- 核查投资协议项下创始人违约责任、赔偿责任、回购责任、清算补偿责任、反稀释补偿责任、平移投资权或其他补偿责任
  是否均被限定以其所持公司股权价值为限；若限制不涉及个人及家庭资产，对既有投资人应判断是否削弱救济，
  对新进投资人应定性为创始人及公司友好并提示执行风险
- 判断本轮安排对指定方权益的影响：增强 / 中性 / 削弱；若削弱，标注 P0/P1/P2
- 对人员、创始股东、核心人员、代持关系或附属文件的新增、删除、替换建立事实核实表，列明变化原因、影响和所需材料
- 每项意见同时标注适用主体/批次、处理类型和证据状态；资料不足时不得输出确定性权利结论

## 四、政府引导 / 地方产业基金额外关注
- 返投 / 落地承诺是否写入协议及交割后安排
- 落地主体是否设立或约定设立
- 税收 / 就业 / 研发 / 生产或运营承诺及未完成后果
