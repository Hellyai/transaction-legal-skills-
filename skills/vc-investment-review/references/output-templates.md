# 输出格式与优先级定义

## 一、优先级定义
- **P0**：签署、交割或打款前必须处理；核心权利缺失或空转。
- **P1**：建议修改；影响执行、谈判地位或证据闭环。
- **P2**：表达优化或可谈判事项。

## 二、TS 快速审核输出
1. 快速结论
2. 已有条款表
3. 缺失条款表
4. 必补建议
5. P0 / P1 / P2 优先级

## 三、投资协议审核输出
1. 交易概要
2. P0 问题
3. P1 问题
4. 修改建议
5. 待确认资料

## 四、股东协议审核输出
1. 总体判断
2. Key Terms 表
3. P0 / P1 问题
4. 既有投资人权利影响（若适用）
5. 修改建议

## 五、既有投资人上轮对比专项输出
当用户身份为既有投资人，且提供或可识别上轮投资协议、股东协议、章程/补充协议、Cap Table 或工商资料时，
必须在投资协议/股东协议审阅后追加本专项；资料不足时仍输出"无法判断项"。

1. 指定方历史投资概览
   - 过往参与轮次
   - 各轮投资金额
   - 各轮投资单价或估值
   - 各轮取得股比及本轮前后股比变化
2. 本轮与上轮投资协议修改要点
   - 交易结构、估值/投资单价、投资金额、交割前提、交割后义务、违约责任、解除、
     豁免/追认、投后义务履行情况
3. 本轮与上轮股东协议修改要点
   - 回购、清算优先、反稀释、优先认购、优先购买/共同出售、MFN、信息权、
     保护性条款、董事席位、创始人限制、赔偿责任、陈述保证
4. 权利平等与新投资人新增权利核查
   - 新投资人是否新增特殊权利、优惠待遇、优先顺位或更强行权机制
   - 指定方是否同步享有该等新增权利
   - 若未同步享有，指定方是否可通过 MFN、平等待遇、补充协议或本轮股东协议修订自动适用
   - 同类权利是否存在差异：权利主体、适用范围、行权门槛、顺位、期限、价格/利率、
     例外豁免、是否需其他方同意
   - 结论：权利平等 / 基本平等但需确认 / 不平等且削弱指定方权益
5. ESOP / 股权结构 / 估值影响
   - 是否新增、发放或扩容 ESOP
   - ESOP 口径是投前还是投后
   - 是否稀释指定方
   - 是否触发指定方保护性条款、优先认购、反稀释或其他同意权
6. 是否削弱指定方权益
   - 结论：增强 / 中性 / 削弱
   - 若削弱，说明削弱方式：删除、限缩、推迟、降顺位、提高行权门槛、夹带豁免、
     历史违约被放弃、经济权益被稀释、新投资人新增权利未向指定方同步适用
   - 标注优先级：P0 / P1 / P2
7. 需确认/需修改事项
   - 缺少资料清单
   - 必须修改事项
   - 可谈判事项

## 六、交割文件最终核验输出
1. 交割前结论
2. 横向一致性问题
3. 各文件自身问题
4. 夹带豁免 / 权利放弃风险
5. 签署 / 打款前必须修正项

## 七、格式与表达要求
- 默认中文；结论先行。
- 用表格呈现条款清单 / Key Terms，便于快速扫读。
- 每条问题写明：位置（条款/页码）、问题、风险、建议修改、优先级。
- 不臆测；文件未写或写不清的，标注"缺失/空转"。
- 投资人权利相关结论用"投资人友好 / 中性 / 不利"定性。
