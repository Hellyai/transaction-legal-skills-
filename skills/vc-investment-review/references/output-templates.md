# 输出格式与优先级定义

## 一、优先级定义
- **P0-签署障碍**：签署、交割或打款前必须解决，否则交易文件、权利或履行存在实质障碍。
- **P0-重大内部决策**：涉及重大经济、治理或退出权变化，必须由有权决策主体明确接受或拒绝。
- **P0-重大谈判事项**：原则上应在签署前争取修改；未修改时必须形成明确的风险接受决定。
- **P1**：建议修改；影响执行、谈判地位或证据闭环。
- **P2**：表达优化或可谈判事项。

每项问题另标注处理类型：**对外谈判 / 内部决策 / 事实核实 / 文本修订 / 交割前提 / 可接受提示**。

## 二、TS 快速审核输出
1. 快速结论
2. 已有条款表
3. 缺失条款表
4. 必补建议
5. P0 / P1 / P2 优先级

## 三、投资协议审核输出
1. 交易概要
2. P0 问题
3. P1 问题
4. 修改建议
5. 待确认资料

## 四、股东协议审核输出
1. 总体判断
2. Key Terms 表
3. P0 / P1 问题
4. 既有投资人权利影响（若适用）
5. 新进投资人友好度分析（若适用）
6. 文本与签署核对
7. 修改建议

## 五、新进投资人专项输出

新进投资人审阅在投资协议/股东协议常规输出基础上，必须追加：

1. 结论状态与资料边界
   - 已确认 / 待文件补充 / 待 Cap Table 核验 / 待公开信息核实
2. 本轮文件矩阵
3. 投资主体—证券—权利映射
4. 交易经济与 Cap Table
   - 投前/投后估值、金额、单价、注册资本、资本公积、股比、ESOP及完全摊薄口径
5. 交易执行与尽调闭环
   - 交割前提、陈述保证、特别赔偿、付款交割、交割后义务及解除退款
6. 核心经济权利
   - 回购、清算、反稀释、MFN、共同出售、拖售及其他退出安排
7. 核心治理权
   - 董事/观察员、股东会与董事会否决、法定人数、信息权及持股门槛
8. 投资人分层与特殊权利
   - 指定方与领投方、其他新投资人及现存投资人的差异
9. 创始人责任与投资人救济
10. 执行清单
   - 对外谈判、内部决策、事实核实、文本修订、交割前提和可接受提示
11. 签署、付款及交割结论

## 六、既有投资人上轮对比专项输出
当用户身份为既有投资人，且提供或可识别上轮投资协议、股东协议、章程/补充协议、Cap Table 或工商资料时，
必须在投资协议/股东协议审阅后追加本专项；资料不足时仍输出"无法判断项"。

1. 结论状态与资料边界
   - 已确认 / 待文件补充 / 待 Cap Table 核验 / 待公开信息核实
2. 文件版本矩阵
3. 主体—轮次—股权批次映射
4. 指定方历史投资概览
   - 过往参与轮次
   - 各轮投资金额
   - 各轮投资单价或估值
   - 各轮取得股比及本轮前后股比变化
5. 本轮与上轮投资协议修改要点
   - 交易结构、估值/投资单价、投资金额、交割前提、交割后义务、违约责任、解除、
     豁免/追认、投后义务履行情况
6. 本轮与上轮股东协议修改要点
   - 回购、清算优先、反稀释、优先认购、优先购买/共同出售、MFN、信息权、
     保护性条款、董事席位、创始人限制、赔偿责任、陈述保证
7. 权利分配变化与特殊投资人权利地图
   - 新投资人向前拉齐的前序权利
   - 本轮新增且全体投资人共享的权利
   - 仅领投方、新投资人或特定投资人享有的权利
   - 指定方被删除、限缩、推迟、降顺位、提高门槛或稀释的权利
   - 人员、主体、数字或事实替换且待核实的事项
   - 新投资人是否新增特殊权利、优惠待遇、优先顺位或更强行权机制
   - 指定方是否同步享有该等新增权利
   - 若未同步享有，指定方是否可通过 MFN、平等待遇、补充协议或本轮股东协议修订自动适用
   - 同类权利是否存在差异：权利主体、适用范围、行权门槛、顺位、期限、价格/利率、
     例外豁免、是否需其他方同意
   - 结论：权利平等 / 基本平等但需确认 / 不平等且削弱指定方权益
8. 本轮协议替代/终止前序轮协议核查
   - 本轮协议是否约定替代、终止、覆盖或重述前序轮投资协议/股东协议
   - 是否存在"完整协议""取代此前约定""原协议终止""各方确认无争议/无违约/无其他权利义务"
     等可能导致前序权利失效的表述
   - 指定方前序轮特殊权利是否在本轮协议中完整承继
   - 前序轮已发生的违约责任、救济权、索赔权、回购触发、反稀释补偿、赔偿责任是否明确保留
   - 若前序协议被替代，是否设置"不豁免历史违约/不影响已产生权利/不影响既有投资人救济"条款
   - 结论：无替代风险 / 有替代但权利已保留 / 替代导致权利或救济可能失效
9. ESOP / 股权结构 / 估值影响
   - 是否新增、发放或扩容 ESOP
   - ESOP 口径是投前还是投后
   - 是否稀释指定方
   - 是否触发指定方保护性条款、优先认购、反稀释或其他同意权
10. 治理权迁移
   - 股东会与董事会事项、门槛、必须同意方及指定方是否有表决权
   - 董事、观察员和一票否决权变化
11. 创始人责任与投资人救济的系统性变化
12. 是否削弱指定方权益
   - 结论：增强 / 中性 / 削弱
   - 若削弱，说明削弱方式：删除、限缩、推迟、降顺位、提高行权门槛、夹带豁免、
     历史违约被放弃、经济权益被稀释、新投资人新增权利未向指定方同步适用、
     本轮协议替代前序协议导致既有权利或救济失效
   - 标注优先级：P0 / P1 / P2
13. 执行清单
   - 缺少资料清单
   - 必须修改事项
   - 可谈判事项
   - 内部决策事项
   - 事实核实事项
   - 签署、付款或放弃权利的前置条件

## 七、文件成果输出规则

当用户要求生成 Word 成果时，在本轮协议目录下新建独立审阅文件夹，文件夹使用 `【项目名-协议名-YYYYMMDD】` 口径；同时审阅多类协议时，“协议名”可统一写为“本轮协议”。不得修改、移动或覆盖原始文件，也不得未经确认外发。

### 1. 既有投资人专项文件
至少输出一份综合审阅意见及一份本轮与上一轮有效文件的对比稿。如同时审阅投资协议和股东协议，默认输出：

- `【项目名-协议审阅意见-YYYYMMDD】.docx`
- `【项目名-投资协议-上轮对比稿-YYYYMMDD】.docx`
- `【项目名-股东协议-上轮对比稿-YYYYMMDD】.docx`

如仅审阅其中一类协议，仅输出综合审阅意见和对应协议对比稿。

审阅意见必须包含：
- 核心结论
- P0 / P1 / P2 风险
- 实质条款修改梳理
- 与上轮协议逐项对比
- 是否削弱指定方权益
- 权利平等与新投资人新增权利核查
- 本轮协议替代/终止前序轮协议核查
- 修改建议
- 每项意见的适用主体/批次、处理类型、证据状态和依据文件/条款/页码

对比稿必须尽量逐字呈现差异；若无法生成原生 Word 修订模式，输出 Word 版逐条对比表并说明技术限制。

### 2. 新进投资人专项文件

默认输出一份综合审阅意见：

- `【项目名-新进投资人协议审阅意见-YYYYMMDD】.docx`

如用户提供同一协议的不同版本并要求比较，再分别输出投资协议或股东协议对比稿。综合审阅意见必须包含本节第五部分的全部专项结构。

### 3. Word 格式要求
- 格式优先 Word；
- 默认字体：楷体；
- 标题：三号；
- 正文：小四；
- 表格内容保持可复制、可继续编辑。

### 4. 文本与签署核对流程
审阅意见输出前，严格执行 `quality-control.md`，完成法律依据、文本、主体、签署、证据和 Word 视觉检查；无法完成的项目必须披露。

## 八、交割文件最终核验输出
1. 交割前结论
2. 横向一致性问题
3. 各文件自身问题
4. 夹带豁免 / 权利放弃风险
5. 签署 / 打款前必须修正项

## 九、格式与表达要求
- 默认中文；结论先行。
- 用表格呈现条款清单 / Key Terms，便于快速扫读。
- 每条问题写明：依据文件及版本、位置（条款/页码）、上轮口径、本轮口径、适用主体及批次、问题、风险、指定方影响、建议、处理类型、优先级、证据状态。
- 不臆测；文件未写或写不清的，标注"缺失/空转"。
- 投资人权利相关结论用"投资人友好 / 中性 / 不利"定性。
