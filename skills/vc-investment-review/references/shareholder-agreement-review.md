# 股东协议审核规则

涉及回购、清算、反稀释、MFN、共同出售或拖售时，必须加载 `economic-rights-review.md`；涉及董事会、股东会、保护性事项或观察员时，必须加载 `governance-review.md`；新进投资人场景同时加载 `new-investor-review.md`，既有投资人场景同时加载 `existing-investor-review.md`。

## 一、需审核的权利条款清单
逐项审核以下权利，并在需要时输出 Key Terms：

- [ ] 合格上市：时间、估值、上市地点、锁定期要求
- [ ] 回购权：触发情形、义务主体、权利主体顺位、回购价格/计算公式、
      回购利率、责任限制、行权期、支付期
- [ ] 优先清算权：参与型/非参与型、触发情形、控制权转移、顺位、清算额
- [ ] 领售权/拖售权：触发时间、估值、同意比例、主体、是否需创始人同意
- [ ] 反稀释权：加权平均或完全棘轮、例外、补偿方式
- [ ] 优先认购权：绝对比例/相对比例、超额认购机制
- [ ] 优先购买权/共同出售权：适用对象、权利主体、比例、超额购买、
      共同出售公式
- [ ] 优先分红权：权利主体、利率、是否累积
- [ ] 保护性条款：股东会/董事会层面、否决权主体、事项清单
- [ ] 董事会/监事会构成：人数、委派权、表决机制、观察员
- [ ] 创始人限制：全职服务、不竞争、转股限制、限制性股权、vesting、离职回购
- [ ] 投资人限制：竞争对手转让限制、投资其他实体限制
- [ ] 信息权和检查权：报表、审计、预算、重大事项通知、检查权
- [ ] ESOP：比例、投前/投后口径、本轮后是否增发、决策机制
- [ ] 最惠国待遇 / 平等待遇
- [ ] 公司 / 创始股东赔偿责任
- [ ] 公司 / 创始人陈述与保证
- [ ] 前序协议替代/终止：过往协议是否被替代，最新有效文件是否影响我方利益
- [ ] 单独投资人权利：是否单独给到某些投资人特殊权利、优惠待遇或更强机制
- [ ] 创始人责任上限：回购、清算、反稀释、平移投资权、违约责任或补偿责任是否以持股为限

## 二、新进投资人额外判断（每项权利都要做）

- 指定方是否明确取得该项权利，权利适用于法律主体还是特定证券/股权
- 是否仅领投方或其他投资人享有，指定方同类权利是否门槛更高、期限更短、顺位更后或例外更多
- 权利是否需要创始人、特定投资人或投资方董事同意而可能空转
- 权利是否因持股门槛、稀释、转让或关联主体拆分而终止
- 回购、清算、反稀释、MFN、共同出售和拖售公式及触发逻辑是否完整、正确且可执行
- 董事、观察员、股东会/董事会否决、法定人数和信息权是否满足投资决策要求
- 公司、创始人及控股股东责任是否被限制，是否排除个人、配偶或家庭财产
- 协议、章程和交割文件是否一致承载核心权利
- 每项意见标注适用主体/证券、处理类型、优先级和证据状态

## 三、既有投资人额外判断（每项权利都要做）
- 未完成文件版本矩阵和主体—轮次—股权批次映射时，仅输出条件性结论
- 是否削弱我方既有权利
- 新老投资人权益是否实质一致
- 回购期限是否被推迟
- 回购、反稀释、优先认购、优先购买、MFN 是否被触发或放弃
- 股东会 / 董事会表决事项是否被修改
- 我方董事席位或一票否决权是否受影响
- 与上轮股东协议逐项对比修改要点，尤其关注回购、清算优先、反稀释、优先认购、
  优先购买/共同出售、MFN、信息权、保护性条款、董事席位、创始人限制、赔偿责任、
  陈述保证是否被删除、限缩、推迟、降顺位或提高行权门槛
- 核查是否新增/发放/扩容 ESOP，ESOP 决策机制是否需要指定方同意，是否导致指定方被稀释
- 结合指定方历史投资轮次、投资金额、投资单价或估值，判断本轮股东协议是否实质削弱指定方权益
- 判断权利是否平等：新投资人是否新增享有指定方没有的权利，或在同类权利项下享有更强保护；
  重点比较权利主体、适用范围、行权门槛、顺位、期限、价格/利率、例外豁免、是否需其他方同意
- 若新投资人新增权利但指定方未同步取得，或指定方同类权利更弱，应作为既有投资人权益削弱风险列示；
  影响核心经济权利、退出权、否决权或董事席位的，原则上标为 P0/P1
- 核查本轮股东协议是否替代、终止、覆盖或重述前序轮股东协议；若前序协议失效，
  必须确认指定方既有特殊权利是否在本轮协议中完整承继，且前序轮已触发的回购、反稀释、
  优先认购、优先购买/共同出售、MFN、信息权、董事席位、保护性条款、赔偿责任和索赔权未被消灭
- 若本轮协议仅写"本协议取代此前全部约定/各方不再依据原协议主张权利"，但未设置前序权利保留条款，
  应作为既有投资人权利失效风险列示；涉及核心退出或救济权的，原则上标为 P0
- 核查最优惠待遇是否同时包含向前和向后适用：既覆盖前轮更优条款，也覆盖未来轮次或其他投资人取得的更优条款；
  若存在该等条款，应判断指定方是否同等享有、是否需主动主张或自动适用、是否排除核心经济权利
- 核查反稀释条款公式是否正确，反稀释补偿方式是股权补偿、现金补偿还是二者择一/并用；补偿主体、
  补偿时点和税费承担是否明确
- 核查共同出售权公式是否正确，尤其是可出售数量、比例分摊、超额出售、多个权利人并行行权时的计算口径
- 核查清算优先权是否有二次分配，即投资人取得优先清算额后是否继续按持股比例参与剩余财产分配
- 核查是否单独给某些投资人额外权利；若指定方未同等享有，应列入权利不平等和既有权益削弱风险
- 核查创始人在股东协议项下违约责任、回购责任、清算补偿责任、反稀释补偿责任、平移投资权或其他补偿责任
  是否均限定以其所持公司股权价值为限，且不涉及个人及家庭资产；若是，对既有投资人需分析救济削弱，
  对新进投资人需定性为创始人及公司友好并提示执行风险
- 建立治理权迁移矩阵，识别事项由股东会向董事会、由全体投资人向投资方董事或特定投资人转移的效果
- 将复合触发条件拆解为原子条件，明确 AND / OR、例外、门槛和必须同意方
- 每项意见同时标注适用主体/批次、处理类型和证据状态
