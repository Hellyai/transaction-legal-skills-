# 投资协议 / 增资协议 / 股权转让协议 审核规则

## 一、重点审核项
- 本轮估值
- 新进投资机构
- 投资总额
- 各投资人投资金额
- 我方股比
- 投前 / 投后 / 完全稀释 Cap Table
- 签署主体是否齐备
- 交割前提条件是否完整
- 交割前过渡期事项
- 交割后义务
- 法律尽调报告要点是否落实
- 违约责任
- 解除
- 多个投资人是否约定各自义务分别且不连带
- 资金用途
- 工商变更、股东名册、出资证明、章程备案等交割后安排

## 二、既有投资人额外审核
- 上一轮投后义务是否已完整履行
- 股权结构是否正确
- 是否要求上一轮投资人过度豁免公司及创始人的违约责任
- 是否触发但未处理反稀释、优先认购、MFN 等权利
- 既有董事席位、否决权或信息权是否被削弱

## 三、政府引导 / 地方产业基金额外关注
- 返投 / 落地承诺是否写入协议及交割后安排
- 落地主体是否设立或约定设立
- 税收 / 就业 / 研发 / 生产或运营承诺及未完成后果
