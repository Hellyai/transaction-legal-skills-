# 输出格式与优先级定义

## 一、优先级定义
- **P0**：签署、交割或打款前必须处理；核心权利缺失或空转。
- **P1**：建议修改；影响执行、谈判地位或证据闭环。
- **P2**：表达优化或可谈判事项。

## 二、TS 快速审核输出
1. 快速结论
2. 已有条款表
3. 缺失条款表
4. 必补建议
5. P0 / P1 / P2 优先级

## 三、投资协议审核输出
1. 交易概要
2. P0 问题
3. P1 问题
4. 修改建议
5. 待确认资料

## 四、股东协议审核输出
1. 总体判断
2. Key Terms 表
3. P0 / P1 问题
4. 既有投资人权利影响（若适用）
5. 修改建议

## 五、交割文件最终核验输出
1. 交割前结论
2. 横向一致性问题
3. 各文件自身问题
4. 夹带豁免 / 权利放弃风险
5. 签署 / 打款前必须修正项

## 六、格式与表达要求
- 默认中文；结论先行。
- 用表格呈现条款清单 / Key Terms，便于快速扫读。
- 每条问题写明：位置（条款/页码）、问题、风险、建议修改、优先级。
- 不臆测；文件未写或写不清的，标注"缺失/空转"。
- 投资人权利相关结论用"投资人友好 / 中性 / 不利"定性。
