# TS / Term Sheet 快速审核规则

> 适用：我方版本 TS 或早期 TS。默认快速完整性审核。

## 一、TS 快速审核优先输出顺序
1. 已有条款
2. 缺失条款
3. 必补条款
4. P0 / P1 / P2 优先级
5. 快速结论

## 二、TS 应包含的条款清单（完整性核对）
逐项核对 TS 是否包含：

- [ ] 融资主体
- [ ] 投资方及指定关联方
- [ ] 创始人 / 创始团队 / 现有股东
- [ ] 投前估值、投后估值
- [ ] 投资总额、各投资人投资金额、我方股比
- [ ] Cap Table / 完全稀释口径
- [ ] ESOP / 期权池
- [ ] 交割前提条件
- [ ] 资金用途
- [ ] 创始人 vesting、全职服务、不竞争、转股限制
- [ ] 回购权
- [ ] 清算优先权
- [ ] 反稀释权
- [ ] 优先认购权
- [ ] 优先购买权 / 共同出售权
- [ ] 领售权 / 拖售权（如适用）
- [ ] 信息权 / 检查权
- [ ] 保护性条款
- [ ] 董事席位
- [ ] 最惠国待遇 / 平等待遇
- [ ] 优先分红权（如适用）
- [ ] 保密
- [ ] 排他
- [ ] 费用
- [ ] 适用法律 / 争议解决
- [ ] 基金特殊要求（政府引导/地方产业基金落地返投，如适用）

## 三、TS 中的 P0 红线
以下任一情形视为 P0（签署前必须处理）：

1. 缺少投资金额、估值或我方股比；
2. 缺少 Cap Table 或完全稀释口径；
3. 缺少交割前提条件；
4. 写了回购权，但缺少回购价格 / 计算公式；
5. 回购权缺少义务主体，无法判断谁承担回购义务；
6. 排他、保密、费用、放弃等约束性条款涉及创始人或现有股东，但相关主体未签署；
7. 基金有返投 / 落地要求，但 TS 未体现。

> ⚠️ **关键提示**：不要只因为 TS 写了"投资人享有回购权"就认为条款完整。
> 若没有回购价格或计算公式（例如仅写"投资本金 + 约定收益"），应提示为重大缺失（P0）。
