# Transaction Legal Skills｜投融资交易文件 AI Skill 工具包

这是一个面向 VC/PE 投融资交易场景的 AI Skill 工具包，主要包含两类能力：

- `vc-investment-review`：交易文件审阅 Skill，用于审阅 TS、投资协议、股东协议及交割文件。
- `captable`：Cap Table 核对 Skill，用于生成、复核和校验融资交易中的股权结构表。

本项目的目标不是让 AI 替代专业判断，而是把投融资文件审阅中的经验、路径和检查清单沉淀成可复用的工作流，让 AI 按固定口径辅助完成初步审阅、风险识别和结构化输出。

## 1. 交易文件审阅 Skill

路径：`skills/vc-investment-review`

该 Skill 用于 VC/PE 投融资交易文件审阅，覆盖：

- TS / Term Sheet
- 投资协议 / 增资协议 / 股权转让协议
- 股东协议
- 交割阶段文件，包括章程、股东会决议、董事会决议、披露函、放弃函等

### 核心审阅逻辑

Skill 会先识别文件类型和我方身份，再进入对应审阅路径。

支持的身份包括：

- 新进投资人
- 既有投资人
- 政府引导基金 / 地方产业基金
- 其他产业投资人

如果是新进投资人，重点关注：

- 本轮估值
- 新进投资机构
- 投资总额及各投资人投资金额
- 我方股比
- 股权结构 / Cap Table
- 交割前提条件
- 交割前过渡期事项
- 交割后义务
- 尽调风险是否落实
- 违约责任、解除、多投资人不连带责任

如果是既有投资人，会额外进行上轮文件对比和权益影响分析，重点关注：

- 上一轮投后义务是否已履行
- 本轮是否过度豁免公司或创始人的历史违约责任
- 原有回购、反稀释、优先认购、优先购买、共同出售、MFN、董事席位、保护性条款等权利是否被削弱
- 新投资人是否获得新增权利、优惠待遇、优先顺位或更强行权机制，而既有投资人未同步享有
- 是否新增、发放或扩容 ESOP，并稀释既有投资人权益
- 指定方过往参与过几轮投资，各轮投资金额、投资单价或估值、取得股比及本轮后股比变化

如果是政府引导基金或地方产业基金，会额外关注：

- 落地安排
- 返投要求
- 地方考核指标
- 税收、就业、研发、生产或运营承诺
- 未完成返投或落地义务的后果

### 典型输出

- 快速结论
- 已有条款表
- 缺失条款表
- P0 / P1 / P2 风险分级
- Key Terms 表
- 投资人友好度判断
- 修改建议
- 既有投资人上轮对比专项分析

## 2. Cap Table 核对 Skill

路径：`skills/captable`

该 Skill 用于投融资交易中的股权结构计算、复核和公式校验，尤其适用于中国公司注册资本口径下的交易文件附件。

覆盖场景包括：

- 增资扩股
- 新股认购
- 老股转让
- 新老股混合交易
- ESOP / 员工持股平台
- 投前、投后、完全稀释后股权结构
- 协议附件版 Cap Table
- Excel 公式化检查表

### 典型输出

- 原始数据表
- 计算逻辑表
- 投后股权结构表
- 完全稀释后股权结构表
- 投资金额、新增注册资本、老股转让、ESOP、最终持股比例的核对项

## 使用方式

如果只使用交易文件审阅 Skill，复制：

```text
skills/vc-investment-review
```

如果只使用 Cap Table 核对 Skill，复制：

```text
skills/captable
```

如果作为完整工具包使用，保留整个 `skills` 文件夹即可。

## 示例 Prompt

```text
请用 vc-investment-review skill，从既有投资人视角审阅这份股东协议，并生成 Key Terms 和上轮对比分析。
```

```text
请用 vc-investment-review skill，快速审核这份 TS，列出已有条款、缺失条款和 P0 风险。
```

```text
请用 captable skill，根据本轮估值、投资金额和现有股东结构，核对投后股权比例是否正确。
```

## 数据安全提示

本仓库只应存放通用 SOP、审阅规则、模板和脱敏示例。上传前请勿放入：

- 客户真实协议或项目文件
- 未脱敏的交易信息
- 尽调报告原文
- API Key、MCP Token、Authorization Header
- 微信、企业微信、网盘缓存文件
- 任何包含客户名称、交易价格、个人信息的敏感材料

## Disclaimer

本项目仅用于辅助法律和投资专业人士进行结构化审阅，不构成法律意见，也不能替代律师或投资团队的最终专业判断。
