# CapTable Skill

用于生成投融资交易中的股权结构表、投后股权结构、完全稀释后股权结构及公式化检查表的 Codex Skill。

## 适用场景

- 增资扩股
- 新股认购
- 老股转让
- 新老股混合交易
- ESOP / 员工持股平台
- 可转债、SAFE、认股权证、反稀释等潜在稀释事项
- 投资协议附件中的股权结构表

## 你需要提供的信息

- 项目名称
- 投前估值
- 本轮投资金额
- 投前股东名册
- 投前注册资本或股份数
- 各投资人投资金额
- ESOP比例及口径
- 是否存在老股转让
- 是否存在潜在稀释事项

## 输出内容

默认生成 Excel 文件，包含：

- 计算逻辑
- 投后股权结构
- 完全稀释后
- 检查
